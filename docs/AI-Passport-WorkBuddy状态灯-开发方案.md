# WorkBuddy 状态灯固件 — 开发方案

> 目标设备：FoloToy AI Passport（ESP32-C3 / 8MB Flash / 无 PSRAM / 240×320）
> 数据源：本机 WorkBuddy 网关 + 本地文件
> 开发方式：WorkBuddy + ESP-IDF 5.5.3
> 状态：方案待确认 → 环境安装中

---

## 一、整体架构

```
┌─────────────────────────────────────────────────────────────┐
│  PC（WorkBuddy 桌面版常驻）                                  │
│                                                             │
│  ①  ~/.workbuddy/sessions/*.json                             │
│      → lastHeartbeat 时间戳（判断在线/离线）                  │
│  ②  ~/.workbuddy/logs/main.log                               │
│      → [TaskNotify] completed 事件（判断忙碌/空闲）           │
│  ③  http://127.0.0.1:<port>/api/v1/status  （备用，需认证）   │
│      → busy / lastCompletedAt                                │
│                          ↓                                  │
│  中转服务 wb-bridge（Node/Python 常驻）                       │
│    · 轮询上述数据源（2s）                                      │
│    · 归约为状态包 {state, task, ts}                            │
│    · 通过 BLE 广播/通知推给工牌                                 │
└─────────────────────────────────────────────────────────────┘
                          ↓ BLE (NimBLE)
┌─────────────────────────────────────────────────────────────┐
│  AI Passport 固件                                            │
│    · 接收 BLE 状态包 → 更新屏幕                                │
│    · OK 短按 → 主动请求最新状态                                 │
│    · 无连接时显示「未连接」                                     │
└─────────────────────────────────────────────────────────────┘
```

**为什么必须中转**：ESP32-C3 无 TLS 证书管理能力，不适合直接访问带认证的 HTTPS；且 `client_secret` 类凭据绝不能落到设备端。中转服务放在 PC 上，天然可信。

## 二、状态模型（三种状态）

| 状态 | 判定条件 | 屏幕显示 | 颜色（RGB565） |
|---|---|---|---|
| **IDLE** | `lastHeartbeat` 距今 < 30s 且无 running 任务 | 绿色圆点 + "WorkBuddy 就绪" | 绿 `0x07E0` |
| **BUSY** | 检测到任务开始事件 | 橙色圆点 + 任务名 + 已运行时长 | 橙 `0xFD20` |
| **OFFLINE** | `lastHeartbeat` 距今 > 60s | 灰色圆点 + "未连接" | 灰 `0x8410` |

**判定逻辑（中转侧）**：
```
1. 扫描 ~/.workbuddy/sessions/*.json
   → 找 lastHeartbeat 最大的那个（= 当前活跃会话）
   → now - lastHeartbeat > 60000ms  → OFFLINE
2. 若在线，tail ~/.workbuddy/logs/main.log 最后 50 行
   → 匹配 task start / completed 事件
   → 有未闭合的 task → BUSY 并提取任务名
   → 否则 → IDLE
3. 打包 JSON，通过 BLE Notify 推送
```

## 三、屏幕 UI 设计（240×320 竖屏）

```
┌────────────────────────────┐
│                            │  ← 顶部留白 40px
│         ●                  │  ← 状态圆点 直径 56px
│                            │
│    WorkBuddy 就绪           │  ← 主状态文字 24px 粗体
│                            │
│  ──────────────────────    │  ← 分隔线
│                            │
│   最后活动                  │  ← 小标签 14px 灰
│   2 分钟前                  │  ← 24px
│                            │
│                            │
│  ┌──────────────────────┐  │
│  │  OK 短按 = 刷新状态    │  │  ← 底部提示条
│  └──────────────────────┘  │
└────────────────────────────┘
```

**BUSY 态变化**：
```
┌────────────────────────────┐
│         ●                  │  ← 橙色 + 呼吸动画（亮度渐变）
│    正在执行任务             │
│                            │
│  ──────────────────────    │
│   任务                       │
│   cockpit-frontend-workflow │  ← 任务名，超长滚动
│                            │
│   已运行                    │
│   01:23                     │  ← 实时计时器
│                            │
│  ┌──────────────────────┐  │
│  │  OK 短按 = 刷新状态    │  │
│  └──────────────────────┘  │
└────────────────────────────┘
```

**按键**：

| 按键 | 事件 | 行为 |
|---|---|---|
| OK | 短按 | 向中转请求最新状态（立即刷新） |
| OK | 长按(500ms) | 切换「详细/简洁」显示模式 |
| UP | 短按 | 手动切换状态（调试用，可关） |
| DOWN | 短按 | 切换亮度（100% / 50% / 10%） |

## 四、BLE 协议设计

**服务 UUID**（自定义）：
```
Service:        0000FFF0-0000-1000-8000-00805F9B34FB
Char (Notify):  0000FFF1-...  ← 中转 → 工牌（状态推送）
Char (Write):   0000FFF2-...  ← 工牌 → 中转（刷新请求）
```

**状态包格式**（紧凑，省 BLE 带宽）：
```
字节  内容
0     state: 0=IDLE, 1=BUSY, 2=OFFLINE
1     flags: bit0=有任务名
2-3   uptime_s: uint16 LE（任务已运行秒数）
4     nameLen: 任务名长度（0~32）
5-36  name: UTF-8 任务名
```
固定 37 字节，一次 Notify 推完。

## 六、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| ESP-IDF 下载慢/失败 | 无法编译 | 后台下载 + 失败重试 |
| 无 PSRAM，中文渲染吃内存 | 可能 OOM | 用点阵位图而非矢量字库；先做英文版验证 |
| 中文缺字 | 显示空白 | 按官方字体检查清单核对，或先用英文 |
| BLE 数据源拿不到 task 名 | 只显示状态 | 降级为「运行中」无任务名 |
| 网关认证拿不到 | 走文件路线 | 已设计为文件优先 |
